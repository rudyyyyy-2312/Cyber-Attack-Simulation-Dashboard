# Cyber Defense Command Center — Setup Guide

## Project Structure
```
OOPC WEBSITE/
├── index.html          ← Open this in your browser
├── style.css           ← Custom animations & cyberpunk styles
├── main.js             ← All frontend logic
```

## 1. Running the Frontend (No Setup Required)

> Simply double-click `index.html` or drag it into any browser.

The website runs fully offline — no server needed.

---

## 2. Compiling & Running the C++ Backend

### Requirements
- **Windows**: Install [MinGW-w64](https://www.mingw-w64.org/) or use the Visual Studio Developer Command Prompt
- **Linux/macOS**: `g++` is usually pre-installed

### Compile
```bash
# From the project root folder
g++ Simulator.cpp Analyzer.cpp -o cdcc_sim -std=c++17
```

### Run
```bash
./cdcc_sim          # Default: 50 simulated attacks
./cdcc_sim 100      # Custom count (e.g. 100 events)
```

This generates `attack_data.json` in the root directory.

## 3. C++ Concepts Used (OOPC Topics)

| Concept | Where |
|---|---|
| **Classes & Objects** | `Analyzer` class in `Analyzer.h/.cpp` |
| **Encapsulation** | Private members `m_blacklist`, `m_sorted_blacklist` |
| **Structs** | `Packet`, `ThreatEvent` |
| **Enums** | `Severity`, `ThreatType` |
| **STL Priority Queue** | `std::priority_queue<ThreatEvent>` in Simulator |
| **STL Unordered Map** | `m_blacklist` — O(1) IP lookup |
| **Binary Search** | `std::binary_search` on sorted IP list |
| **Operator Overloading** | `operator<` on `ThreatEvent` for queue ordering |
| **File I/O** | `std::ofstream` writing JSON output |
| **Algorithm** | Shannon entropy for payload analysis |
| **Chrono** | Timestamps using `std::chrono` |
| **Random** | `std::mt19937` Mersenne Twister PRNG |
| **Templates** | `randChoice<T>()` helper function |
| **Multithreading** | `std::this_thread::sleep_for` |
